## Проблеми ринку

**🥀 Що не працює**

- Під виглядом «люкс» і «преміум» продають мас-маркет
- Каталог люкс-готелів без обличчя — красиво, але не викликає довіри

**🤍 Що працює**

- Емоція «діти + подорожі» — найсильніша тема для сімейної аудиторії

> Преміум-клієнт купує не каталог. Він купує людину, якій довіряє свою відпустку.

## Воронка продажів

1. **Reels дає охоплення.** Кожен Reels закінчується кодовим словом: «ТУР», «ЗИМА», «МАЛЬДІВИ». Коментарі розганяють алгоритм; добірки «збережи собі» — формат-чемпіон преміум-ніші
2. **Direct: підбір за 24 години.** Людина пише кодове слово — отримує персональний підбір. Швидко, тепло, без анкет на 20 питань
3. **Договір + оплата на ФОП.** Момент, де вмикається історія: «я знаю, що буває без договору». Безпека — продаючий аргумент
4. **Супровід 24/7 → відгук → хайлайт.** Кожен клієнт стає соцдоказом. З місяця 2–3 підключаємо таргет на вже живу сторінку

| Що є | Формат |

| Фото Діани | пости/каруселі «знайомство», обкладинки |

| Сток туроператорів | faceless-відео з озвучкою, добірки готелів |

Пропорція старту: ~80% каруселі + відео з озвучкою. Розмовні Reels — після знімального дня.

## Як клеїться тревел-відео (для всіх відео з озвучкою)

- **Хук 0–2 сек** = найвидовищніший кадр (дрон або wow-локація) + титр
- Далі кадри по **1,5–2,5 сек** із чергуванням масштабу: загальний (дрон) → середній (готель, пляж) → деталь (вода, їжа, руки)
- У кожному кліпі є рух — камери або в кадрі
- Фінал — фірмовий кадр + логотип

**Вимоги до матеріалу:** відео вертикальне 9:16 (фото можна 4:5), якість від 1080p, без чужих водяних знаків і вшитого тексту.
