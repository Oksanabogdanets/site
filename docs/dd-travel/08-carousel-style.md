# Фірмовий стиль каруселей — D&D Travel Club

Погоджено 16.09.2026 на каруселі 1 (слайди 1–3). Усі наступні каруселі — у цьому стилі.
Рендер: [`tools/carousel.py`](tools/carousel.py) — відтворює стиль автоматично.

## Кадр

- **Формат:** 1080 × 1350 px (4:5), PNG
- **Фото:** на весь кадр, без рамок і плашок. Кроп по центру, вертикальний фокус підбирається під кадр
- **Стиль фото:** преміум-тревел — басейн на заході, пляж без людей, вид з тераси, деталі сервісу. Тепла або нейтральна гама, без перенасичення. Не сток «з посмішками»

## Композиція

```
┌──────────────────────────────┐
│           D&D                │  ← логотип, центр, y = 56
│        TRAVEL CLUB           │
│                              │
│                              │
│          ФОТО                │
│                              │
│                              │
│  Заголовок антиквою          │  ← текстовий блок знизу ліворуч
│  у два рядки                 │     x = 60, ширина до 930
│  Підзаголовок гротеском      │
│  у один-два рядки            │  ← низ блоку = 1080 (270 px від краю)
│ · · · сліпа зона Instagram · │  ← сюди текст не заходить
└──────────────────────────────┘
```

- **Текст — знизу ліворуч.** Лівий край x = 60. Нижня межа блоку — 270 px від нижнього краю: у стрічці Instagram цю смугу перекривають підпис і кнопки
- **Логотип — угорі по центру,** компактний: «D&D» антиквою 50 px + ромб + «TRAVEL CLUB» розрядкою 16 px
- **Номерів слайдів немає.** Заголовок сам несе структуру

## Типографіка

| Елемент | Шрифт | Розмір | Колір |
|---|---|---|---|
| Заголовок | **Lora Regular** (антиква) | 60 px, інтерліньяж 70 | #FFFFFF |
| Підзаголовок | Liberation Sans Regular (гротеск) | 31 px, інтерліньяж 41 | #EBEBEB |
| Акцентний абзац | той самий гротеск | 31 px | #FFFFFF |
| Логотип «D&D» | Lora Regular | 50 px | #FFFFFF |
| Логотип «TRAVEL CLUB» | Jura Medium, трекінг 7 | 16 px | #FFFFFF |

- Заголовок — **речення, не капс, не жирний.** Антиква перегукується з серифом у самому знаку D&D — це і є айдентика
- Один акцент на слайді — заголовок. Підзаголовок нейтральний
- Заголовок до 2 рядків, підзаголовок до 3. Довше — ріжемо текст, не шрифт

## Затемнення (підкладка)

- **Знизу — під текст:** від верхньої межі блоку (мінус 30 px) до низу кадру. Інтенсивність 160/255, вгору сходить за 340 px, крива 1.3, розмиття 28 px
- **Згори — під логотип:** легке, 95/255, сходить до 22 % висоти
- Затемнення **не має ставати чорним екраном** — фото повинне читатись і під текстом. Якщо не вистачає контрасту — обрати інше фото, а не тиснути підкладку

## Іншомовне

Назви місць і брендів у заголовках лишаємо латиницею як є (Anse Source d'Argent, Palm Jumeirah). В озвучці відео — кирилицею, див. `05-content-videos.md`.

## Як відтворити

```bash
pip install Pillow numpy
python3 docs/dd-travel/tools/carousel.py --photos ./photos --out ./slides
```

Фото кладемо в папку `photos/`, тексти слайдів — у список `SLIDES` у скрипті або через `--slides slides.json`.

## Що ще не закрито

- Справжній файл логотипу (PNG з прозорим фоном) — зараз логотип відмальовується шрифтами, схоже, але не ідентично
- Фото у повній роздільності — скріншоти Pinterest дають 590 px по ширині, для стрічки прийнятно, для друку ні
