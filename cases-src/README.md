# Джерела клону сайту кейсів (cases/)

- `ra.html` — оригінальна сторінка reels-agency.ru (Tilda), знята 06.09.2026
- `ra-img/` — 93 оригінальні картинки (для інвентарю; на сайт ідуть лише іконки/лінії)
- `assets/` — ассети Оксани: кадри c1–c14, фото p1–p25, картки профілів, бейдж, лого, формати
- `gen_assets.py` — генерує assets/ (ffmpeg кадри, PIL фото, Chrome headless для карток)
- `build.py` — збирає cases/index.html + cases/img/: локалізує картинки, міняє кольори на #f6d4aa, тексти → українською, лінки → Direct/Telegram, прибирає трекери/форму

Правити тексти: список `T` у build.py → `python3 build.py` → git commit → push.
Шляхи в скриптах вказують на scratchpad сесії — перед запуском змінити `S`/`A`/`IMG` на цю папку.
